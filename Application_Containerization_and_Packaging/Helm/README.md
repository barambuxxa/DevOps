#Helm

Для чего он нужен? Допустим у нас есть манифест файлы deployment и service. На их основе мы можем запустить кластеры. НО! Все значения в этих yaml файлах прописаны жёстко. И если нам надо будет заново поднять deployment, но с другими значениями, нам надо всё скопировать и сделать изменения. Helm позволяет решить эту проблему следующим способом. Меняем в манифестах жёсткие значения на переменные. А потом уже можно запускать chartы прописывая значения при создании или делать обновление текущего helm через upgrade.

Файл Chart.yaml содержит техническую информацию, на процесс не влияющий.

Файл values.yaml содержит переменные. Эти переменные мы будем прописывать в манифестах.

Папка template содержит манифесты deployment, service, но уже не с жёстко прописанными значениями, а с переменными. Установка через helm должна осуществляться в каталоге Chart.

Для развёртки, нам необходимо сперва установить Helm. Сделать это можно следующим образом:

1. Скачиваем скрипт установки
- curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3


2. Ставим права на запуск скрипта:
- chmod 700 get_helm.sh
3. Запускаем скрипт:
- ./get_helm.sh

4. Теперь мы готовы к запуску нашего Chart на k8sMaster. 
- helm install app2 . --set replicaCount=4

Тут мы запускаем сборку через helm, и сразу передаём количество реплик

Посмотреть результат запуска можно командой 
- helm list

В последующем мы можем изменять настройки, изменяя аргументы командой
- helm upgrade
